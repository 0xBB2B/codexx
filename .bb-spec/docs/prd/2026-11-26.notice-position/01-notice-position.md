# 提示条的位置

## 用户故事
### P0：作为用户，我想要弹出的提示不挡住我要点的按钮和要填的输入框，以便提示出现时不用先关掉它就能接着操作

**用例（主路径）**
- 场景：小林已登录 ChatGPT，转发开着，ChatGPT 正在运行，主窗口只有一个配置「中转」。
- 操作：点「只用中转」开关，马上又想点「重新检测」。
- 预期：左上角弹出成功提示「已切换到「只用中转」」；转发开关、「只用中转」开关、「重新检测」都没被盖住，直接能点；窗口高度没变。

**用例（边界 / 异常）**
- 场景：主窗口同时有一条成功提示「已保存「中转」」和一条错误提示「本机转发服务没能启动」（带「重试」按钮）。预期：两条从左上角往下排，间距 8px，都不盖转发总览的开关、「重新检测」和「中转配置」卡片里的「编辑」「删除」「添加配置」。
- 场景：首次设置窗口保存时写不进设置文件，弹出最长的错误提示「没有保存」。预期：提示条在左上角，盖住大标题和说明，不盖「名字」输入框。
- 场景：编辑配置弹窗里 API Key 无效，点「保存」。预期：弹窗不关，错误提示出现在标题下面、「名字」上面，下面的字段和按钮往下移，弹窗变高；点 ✕ 后提示消失，弹窗变回原来的高度。

## 约束
- C1 主窗口的提示条浮在窗口内容上面，不占布局，出现和消失时窗口高度不变；左上角起始：距标题栏下沿 12px、距窗口左边 24px，宽 376px；多条从上往下排，间距 8px。
- C2 主窗口有一条或两条提示时，提示条不与当时显示的转发开关、「只用中转」开关、「重新检测」、「编辑」、「删除」、「添加配置」、「检查更新」中任何一个重叠：转发开着时包括带按钮的错误提示；没有找到 ChatGPT 时转发是关着的（没有「接入方式」一行），这条最长的错误提示也不盖住其余按钮和开关。
- C3 首次设置窗口的提示条浮在内容上面，不占布局，窗口高度不变；左上角起始：距标题栏下沿 12px、距窗口左边 24px，宽 608px；多条从上往下排，间距 8px。
- C4 首次设置窗口只有一条提示时（包括"没有保存"这条最长的错误提示），提示条不与三个输入框、显示 / 隐藏 API Key 按钮、「完成设置」中任何一个重叠。
- C5 添加配置、编辑配置弹窗里不属于某一个字段的错误提示，插在弹窗正文最上面：标题下面 12px、第一个字段上面 20px，和字段一样宽（左右各距弹窗边 24px），没有阴影；提示条占布局，出现时下面的字段和按钮整体下移、弹窗变高，点 ✕ 消失后弹窗变回原来的高度；提示条不与任何控件重叠。
- C6 提示条本身的样子、文案和去留规则不变：成功和信息 4 秒自动消失，警告和错误留到点 ✕ 或问题解决，标题和级别都相同的提示原位替换。
- C7 macOS 和 Windows 两端的位置、宽度和行为一致（两端都从标题栏下沿往下 12px 开始）。

## 验收
- [ ] C1：主窗口弹出一条提示时，提示条左上角在标题栏下沿往下 12px、窗口左边往右 24px，宽 376px；弹出前后窗口高度相同；两条提示时第二条在第一条下面 8px。
- [ ] C2：主窗口在"刚切换成功""一条错误 + 一条成功""没有找到 ChatGPT（转发关着）"三种情况下，提示条的矩形和当时显示的每个按钮、开关的矩形都不相交。
- [ ] C3：首次设置窗口弹出一条提示时，提示条左上角在标题栏下沿往下 12px、窗口左边往右 24px，宽 608px；弹出前后窗口高度相同。
- [ ] C4：首次设置窗口在"连接失败""没有保存（写不进设置文件）"两种情况下，提示条的矩形和三个输入框、显示 / 隐藏按钮、「完成设置」的矩形都不相交。
- [ ] C5：编辑配置弹窗保存失败时，错误提示条在标题下面 12px、「名字」字段上面 20px，宽度和字段相同；弹窗比没有提示时高出提示条高度加上下间距；提示条不和任何控件相交；点 ✕ 后弹窗高度回到没有提示时的值。添加配置弹窗相同。
- [ ] C6：提示条颜色、内边距、圆角、✕ 按钮和改动前相同；成功提示 4 秒后消失，错误提示不自动消失；同标题同级别的提示仍原位替换。
- [ ] C7：在 macOS 和 Windows 上分别走一遍 C1～C5，位置、宽度和行为相同。

## 验证路径
1. 主窗口转发开着、ChatGPT 运行中，点「只用中转」开关 → 左上角弹出成功提示，量位置和宽度符合 C1；立刻点「重新检测」能点到。
2. 让本机转发服务端口被占用后打开转发，再保存一次配置 → 出现一条错误 + 一条成功，两条往下排，都不盖开关和按钮。
3. 首次设置窗口填一个连不上的 Base URL 点「完成设置」→ 左上角错误提示宽 608px，不盖输入框，窗口高度不变。
4. 编辑配置弹窗填无效的 API Key 点「保存」→ 错误提示插在标题下面，弹窗变高；点 ✕ → 弹窗变回原高。
