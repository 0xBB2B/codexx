# 直接下载本平台安装包

## 用户故事
### P0：作为助手的用户，我想点新版本提示就直接拿到本平台的安装包，以便不用在发布页上自己找文件

**用例（主路径）**
- 场景：小林在 macOS 上用的是 0.1.1，GitHub 上最新正式版是 0.1.2，附件里有 `model-bridge-0.1.2-macos.dmg` 和 `model-bridge-0.1.2-windows-setup.exe`。
- 操作：打开菜单栏面板，点更新项「发现新版本 0.1.2」。
- 预期：更新项标题下面的副标题是「下载安装包」；点了之后默认浏览器直接下载 `model-bridge-0.1.2-macos.dmg`，没有显示发布页；菜单关闭；助手自己没有下载任何文件。

**用例（主路径，Windows 主窗口）**
- 场景：小王在 Windows 上用的是 0.1.1，最新正式版同上。
- 操作：打开主窗口，点底部状态区最右边的「新版本 0.1.2」。
- 预期：默认浏览器直接下载 `model-bridge-0.1.2-windows-setup.exe`；读屏软件读这个按钮是「发现新版本 0.1.2，下载安装包」。

**用例（边界：发布信息里没有本平台安装包）**
- 场景：最新正式版 0.1.2 的附件里只有 `model-bridge-0.1.2-windows-setup.exe`，小林在 macOS 上。
- 操作：打开菜单栏面板看更新项，再点它。
- 预期：副标题是「打开下载页」；主窗口按钮的可访问名称是「发现新版本 0.1.2，打开下载页」；点了之后默认浏览器打开 0.1.2 的发布页。

## 约束
- C1 发现新版本时，在这个版本发布信息的附件清单里找本平台的安装包：macOS 找文件名恰好是 `model-bridge-<版本>-macos.dmg` 的附件，Windows 找 `model-bridge-<版本>-windows-setup.exe`，`<版本>` 是去掉开头 `v` 的标签名。下载地址必须以 `https://github.com/` 开头才算找到。
- C2 找到本平台安装包时：
  - 菜单面板（macOS 菜单栏面板、Windows 托盘面板）的更新项标题是「发现新版本 <版本>」，副标题是「下载安装包」。
  - 主窗口底部状态区按钮的文字是「新版本 <版本>」，可访问名称是「发现新版本 <版本>，下载安装包」。
  - 点更新项或状态区按钮，用默认浏览器打开这个安装包的下载地址；菜单面板点完关闭。
- C3 没找到本平台安装包时（附件清单里没有、文件名对不上、或地址不以 `https://github.com/` 开头）：
  - 仍然提示新版本，更新项副标题是「打开下载页」，状态区按钮的可访问名称是「发现新版本 <版本>，打开下载页」，按钮文字仍是「新版本 <版本>」。
  - 点了用默认浏览器打开这个版本的发布页。
- C4 助手自己不下载、不保存、不打开、不安装安装包；点击只交给默认浏览器打开地址。
- C5 自动检查和手动点「检查更新」发现新版本时，提示文字和点击结果都按 C1～C3 处理，两种检查方式没有区别。

## 验收
- [ ] C1：模拟最新发布 0.1.2 的附件有 `model-bridge-0.1.2-macos.dmg`、`model-bridge-0.1.2-windows-setup.exe` → macOS 端取到 dmg 的地址，Windows 端取到 setup.exe 的地址；附件名是 `model-bridge-0.1.1-macos.dmg`（版本不对）或 `ModelBridge.dmg` → 算没找到；地址是 `https://example.com/model-bridge-0.1.2-macos.dmg` → 算没找到。
- [ ] C2：找到本平台安装包时，菜单面板更新项显示「发现新版本 0.1.2」和副标题「下载安装包」；状态区按钮文字「新版本 0.1.2」、可访问名称「发现新版本 0.1.2，下载安装包」；点更新项和点按钮都用默认浏览器打开安装包下载地址，菜单面板随后关闭。
- [ ] C3：附件里没有本平台安装包时，副标题「打开下载页」，可访问名称「发现新版本 0.1.2，打开下载页」，按钮文字「新版本 0.1.2」；点了打开 0.1.2 的发布页。
- [ ] C4：点击前后，助手没有发起下载请求，「下载」文件夹和助手的程序文件里没有助手写入的安装包。
- [ ] C5：自动检查发现新版和手动点「检查更新」发现新版，两种情况下更新项副标题、可访问名称和点击打开的地址相同。

## 验证路径
1. 在 macOS 上装 0.1.1，最新正式版 0.1.2 带两个安装包 → 打开菜单栏面板 → 看到「发现新版本 0.1.2」「下载安装包」→ 点它 → 浏览器下载 `model-bridge-0.1.2-macos.dmg`，菜单关闭。
2. 打开主窗口 → 用旁白读状态区最右按钮，读出「发现新版本 0.1.2，下载安装包」→ 点它 → 浏览器再次下载同一个 dmg。
3. 在 Windows 上重复第 1、2 步 → 下载的是 `model-bridge-0.1.2-windows-setup.exe`。
4. 模拟最新发布的附件里没有本平台安装包 → 副标题变成「打开下载页」→ 点它 → 浏览器打开 0.1.2 的发布页。
