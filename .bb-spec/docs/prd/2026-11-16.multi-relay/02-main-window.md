# 主窗口新布局

## 用户故事

### P0：作为用户，我想打开主窗口就看清转发开没开、用的哪种接入方式，窗口不要太高

**用例（主路径）**
- 场景：小周已登录 ChatGPT，有 3 个中转配置，转发开着。
- 操作：从菜单栏打开主窗口。
- 预期：窗口从上到下是转发总览、中转配置卡片、底部状态行；接入方式的取值「官方 + 中转」一眼可见；macOS 窗口高约 649px。

**用例（边界）**
- 场景：小周关掉「使用中转」开关。预期：转发总览变成白底灰边，只剩标题和一句说明，没有接入方式那一行；每个配置的状态和底部都写「转发关闭时不获取」。

## 约束

- C1 主窗口宽 620px，从上到下：标题栏、转发总览、「中转配置」卡片、底部状态行。没有「运行状态」卡片，也没有「中转连接」卡片。3 个配置、转发开着时 macOS 高约 649px，Windows 约 633px（允许 ±12px）。
- C2 转发总览，转发开着时：
  - 浅绿底 #e7f2f0 加主色边框；左边 48px 应用图标，中间标题「使用中转 · 已开启」，标题下一句说明，最右是开关。
  - 说明：「官方 + 中转」方式写「官方模型在上，中转模型在下；选官方模型时仍访问官方服务。」；「只用中转」方式写「不用登录 ChatGPT。只有中转模型，默认选中「<默认配置名> · auto」。」，所有配置都没有 auto 时后半句写「没有默认选中的模型。」（默认配置名的规则见多中转配置一节）。
  - 第二行：灰色标签「接入方式」，深色加粗的方式名（「官方 + 中转」或「只用中转」），灰色的检测结果（「· 已检测到 ChatGPT 登录」「· 没有检测到 ChatGPT 登录」或检测失败时「· 沿用上次的方式」），最右是「重新检测」按钮。
- C3 转发总览，转发关着时：白底灰边，标题「使用中转 · 已关闭」，说明「已关闭：Codex 配置已还原为开启前的样子。」，没有接入方式那一行。macOS 窗口高约 593px。
- C4 点「重新检测」：按钮变成转圈加「正在检测…」并不可点，直到检测结束；结果和提示文字按原有的接入方式规则（方式没变时提示「接入方式没有变化」；检测失败时浮出黄色提示「没能检测 ChatGPT 登录状态」「沿用上次的方式。可以稍后点「重新检测」再试。」）。
- C5 底部状态行，从左到右：版本号、绿点「后台运行中」、对勾「ChatGPT 已检测到」、对勾「中转模型 N 个（M 个配置）」，最右「检查更新」。标签灰色，取值深色加粗。转发关着时写「中转模型 转发关闭时不获取」。N 是所有配置这次可用的模型数之和，M 是配置个数。
- C6 所有提示浮在窗口上方，不改变窗口高度（沿用现有提示规则）。
- C7 macOS 和 Windows 只有这些不同：Windows 标题栏高 32px、标题靠左、前面 16px 应用图标、右边系统三个按钮；Key 的保存位置写「系统凭据管理器」；首次设置完成页写「任务栏通知区域」。

## 验收

- [ ] C1：3 个配置、转发开着时打开主窗口，区块顺序和规定一致，没有「运行状态」卡片；量窗口高度在规定范围内。
- [ ] C2：两种接入方式、都没有 auto 三种情况下，标题、说明、接入方式一行的文字和颜色、加粗与规定一致。
- [ ] C3：关掉开关 → 总览变白底，只有标题和规定说明；窗口变矮。
- [ ] C4：点「重新检测」→ 按钮禁用并显示「正在检测…」；方式没变、检测失败两种情况的提示与规定一致。
- [ ] C5：底部状态行的文字和数字与规定一致；关掉转发后写「转发关闭时不获取」。
- [ ] C6：出现提示时窗口高度不变。
- [ ] C7：Windows 主窗口与 macOS 的差异只有规定的几处。

## 验证路径

1. 打开主窗口 → 看到转发总览、中转配置、底部状态行三块。
2. 关掉、再打开开关 → 总览在白底和浅绿底之间切换，接入方式一行随之出现和消失。
3. 点「重新检测」 → 按钮显示「正在检测…」，结束后浮出提示。
