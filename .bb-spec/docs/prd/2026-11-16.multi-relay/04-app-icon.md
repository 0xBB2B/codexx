# 应用图标与菜单栏、托盘图标

## 用户故事

### P0：作为用户，我想一眼认出模型接入助手

**用例（主路径）**
- 场景：小周在 Mac 上打开新下载的 `model-bridge-<版本>-macos.dmg`。
- 操作：把 App 拖进「应用程序」，打开它。
- 预期：dmg 窗口、「应用程序」文件夹、系统设置的登录项里都显示绿色圆角方形底板、白色双向箭头的图标；菜单栏出现单色的双向箭头图标；主窗口转发总览左边显示 48px 的应用图标。

**用例（边界）**
- 场景：小林在 Windows 上把任务栏从浅色切成深色。预期：托盘图标从深色 #172b3a 变成白色。

## 约束

- C1 图形：100×100 画布上，圆心 (50,50)、半径 34 的圆，加路径 `M31.5 42.6H68.5l-9.6-9.6M68.5 57.4H31.5l9.6 9.6` 的两个箭头；只描线不填充，线端和拐角为圆头。线宽按显示尺寸：64px 及以上为画布边长的 6%；24～48px 为 9%；16px 为 12%，并去掉外圈，箭头路径改为 `M22 38H78l-13-13M78 62H22l13 13`。
- C2 macOS 应用图标：底板 #0f766e、图形 #ffffff。1024px 画布上底板 824×824px 居中、四周各留 100px、圆角 184px，其余尺寸按比例；32px 四周留 2px，16px 四周留 1px；图形缩到底板大小居中。提供 16、32、128、256、512、1024px。
- C3 macOS 应用图标出现在：App 本身（Finder、「应用程序」）、dmg 安装包窗口、系统设置的登录项。
- C4 Windows 应用图标：底板铺满画布、#0f766e，256px 画布上圆角 48px，其余尺寸按比例；图形 #ffffff，缩到画布的 88% 居中。提供 16、24、32、48、256px。
- C5 Windows 应用图标出现在：ModelBridge.exe（任务栏、开始菜单、窗口左上角标题栏）、安装程序、「应用和功能」里的卸载项。
- C6 macOS 菜单栏图标：18×18px，同一图形、没有底板、线宽 9%、图形放大到 1.2 倍居中；作为模板图标交给系统，颜色由系统按菜单栏深浅自动换。替换现在的系统符号。
- C7 Windows 托盘图标：16×16px，同一图形（16px 规则：线宽 12%、去掉外圈）、没有底板；任务栏为浅色时颜色 #172b3a，深色时 #ffffff，系统切换深浅色后托盘图标随之更新。替换现在运行时画的青色实心圆。
- C8 窗口里的应用图标：主窗口转发总览左边 48px；添加、编辑配置弹窗头部 24px；Windows 主窗口标题栏 16px。
- C9 图标文件里不含任何真实服务品牌、地址或其他公司的商标图形。

## 验收

- [ ] C1：从图标源文件导出的 1024px、32px、16px 位图，和按规定参数画出的参考图逐像素对比，差异像素占比不超过 1%。
- [ ] C2：macOS 图标文件包含 16、32、128、256、512、1024px 各尺寸；1024px 图的四个角落（距边 50px 处）是透明的，正中像素是 #ffffff 或 #0f766e。
- [ ] C3：用打包脚本打出 dmg，App 包的 Info.plist 指向图标文件，Finder 中 App 和 dmg 窗口显示新图标；登录项里显示新图标。
- [ ] C4：Windows 图标文件包含 16、24、32、48、256px 五个尺寸，256px 图底板铺满、四角圆角处透明。
- [ ] C5：ModelBridge.exe 的文件图标、安装程序图标、卸载项图标都是新图标。
- [ ] C6：macOS 菜单栏显示单色双向箭头；切换系统浅色、深色模式，图标颜色跟着变。
- [ ] C7：Windows 托盘显示单色箭头；任务栏设为浅色时图标为 #172b3a，深色时为 #ffffff，切换后不用重启就更新。
- [ ] C8：主窗口、配置弹窗、Windows 标题栏里的图标尺寸和位置与规定一致。
- [ ] C9：人工核对图标图形；图标目录里没有品牌信息。

## 验证路径

1. 运行 macOS 打包脚本 → 打开 dmg，看到新图标；装好后菜单栏显示单色图标，切换深浅色模式确认变色；主窗口左上转发总览里有 48px 图标。
2. 在 Windows 上安装 → 安装程序、开始菜单、任务栏、标题栏显示新图标；托盘显示单色图标，切换任务栏深浅色确认变色。
