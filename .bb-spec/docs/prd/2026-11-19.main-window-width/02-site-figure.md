# 官网 App 界面图同步加宽

## 用户故事

### P1：作为访问官网的人，我想看到和实际一样宽的 App 界面图，以便知道装上后长什么样

**用例（主路径）**
- 场景：小林用电脑浏览器打开官网，浏览器窗口宽 1200px。
- 操作：在「界面长什么样」区块里依次点页签「首次设置」「主窗口」「菜单栏菜单」。
- 预期：三张界面图都按 760px 宽显示，内容和文字和现在一样。

**用例（边界 / 异常）**
- 场景：用手机浏览器打开，窗口宽 375px。预期：界面图缩到 42%，约 319px 宽，页面没有横向滚动条。
- 场景：窗口宽 320px。预期：界面图缩到 37%，约 281px 宽，页面没有横向滚动条。

## 约束

- C1 三张 App 界面图（首次设置、主窗口、菜单栏菜单）按 760px 宽画，图里的内容和文字不变。
- C2 浏览器窗口宽 809px 及以上，界面图不缩放；601～808px 缩到 65%；357～600px 缩到 42%；356px 及以下缩到 37%。
- C3 在上面每个宽度区间里，页面都没有横向滚动条。
- C4 官网其他区块不变。

## 验收

- [ ] C1：浏览器窗口宽 1200px，切三个页签 → 每张界面图宽 760px，内容和改前一致。
- [ ] C2：窗口宽 808px → 界面图约 494px 宽；600px → 约 319px；356px → 约 281px；809px → 760px。
- [ ] C3：窗口宽 1200、808、700、600、500、375、356、320px 时 → 页面都没有横向滚动条。
- [ ] C4：除「界面长什么样」区块的界面图外，其他区块和改前一样。

## 验证路径

1. 本地构建官网，用浏览器打开首页。
2. 把浏览器窗口宽度依次调到 1200、808、600、356、320px → 界面图宽度分别符合 C2，没有横向滚动条。
3. 切换三个页签 → 每张图的内容和改前一致。
