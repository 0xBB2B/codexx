# 术语表

> 全项目术语唯一权威源，仅 /prd 维护。跨语言 / 跨文档以英文锚点对齐；别名只登记实际用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| relay | 用户另外购买、通过 Base URL 和 API Key 访问的第三方模型服务，提供 Responses API；公开内容里不出现它的真实名称和地址 | 简体「中台」 |
| official-model | ChatGPT 当前版本自带模型清单里的模型，请求最终发往官方服务 | 简体「官方模型」 |
| relay-model | 中台模型列表接口返回、并且在内置参数表里有参数的模型，请求最终发往中台 | 简体「中台模型」 |
| auto-model | 中台提供的、由中台自动选择具体模型的模型，模型名为 `auto` | 简体「auto 模型」「auto 智能模型」 |
| parameter-table | 随本工具版本发布的一张表，写明主流公开模型的上下文窗口、思考等级、是否支持图片输入 | 简体「内置参数表」「参数表」 |
| merged-catalog | 本工具生成的模型目录文件：官方模型在前，中台模型在后；Codex 的模型选择器按它显示 | 简体「合并模型目录」「合并目录」 |
| local-proxy | 本工具在本机提供、只接受本机连接的转发服务；按请求里的模型把请求转到官方服务或中台 | 简体「本机转发服务」「本机代理」「本机分流」 |
| forwarding | 本工具的开关状态：开启时 Codex 配置写入了接入项，Codex 请求经过本机转发服务；关闭时 Codex 配置是开启前的样子 | 简体「转发」 |
| access-entries | 本工具在 Codex 用户配置里写入或移除的几项：`openai_base_url`、`model_catalog_json`、`model`，以及被移除的 `model_provider` | 简体「接入项」 |
| login-start | 用户登录系统后自动启动本工具的设置，默认开启，可以在菜单里关闭 | 简体「登录时启动」 |
