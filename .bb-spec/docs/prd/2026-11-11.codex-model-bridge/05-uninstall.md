# 卸载

## 用户故事

### P0：作为用户，我想干净地卸载工具，以便 Codex 回到安装前的样子

**用例（主路径）**
- 场景：小林开着转发，ChatGPT 正在运行。
- 操作：在菜单里点「卸载模型接入助手…」，在弹窗里点「卸载」。
- 预期：
  - 弹窗先列出卸载会做什么：还原 Codex 配置；删除系统凭据库里的 API Key 和本工具保存的 Base URL；取消「登录时启动」；删除本工具。
  - 弹窗也写明不会删除什么：ChatGPT、聊天记录、用户自己的其他 Codex 设置。
  - 点「卸载」后显示"正在卸载"。完成后提示"已卸载"，请用户重启 ChatGPT，并提供「立即重启 ChatGPT」和「稍后自己重启」。入口图标消失。

**用例（边界 / 异常）**
- 场景：安装后，用户手动改过本工具写入的接入项。操作：卸载。预期：卸载暂停，这时还没有删除任何东西。弹窗写明是哪一项、配置文件在哪，提供「取消卸载」「打开所在文件夹」「重新检查」三个按钮。
- 场景：Windows 用户从系统的"应用和功能"里卸载。预期：执行和菜单卸载相同的还原和清理步骤。

## 约束

- C1 菜单里提供「卸载模型接入助手…」，点击后先弹窗说明会删除什么、不会删除什么，用户确认后才执行。
- C2 卸载先还原 Codex 接入项：逐项恢复成安装前的值，原来没有的删掉，其他内容不动。
- C3 任何一个接入项的当前值和本工具写入的值不一致时，卸载暂停，不改动任何文件，也不删除任何东西；显示具体是哪一项和配置文件的位置，提供「取消卸载」「打开所在文件夹」「重新检查」。
- C4 还原成功后，依次删除：系统凭据库里本工具的 API Key、本工具保存的 Base URL 和运行数据、登录时启动项、本工具生成的合并模型目录、程序本身。
- C5 卸载不删除也不修改：ChatGPT 程序、ChatGPT 和 Codex 的聊天数据、`auth.json`、Codex 配置里接入项以外的内容、安装前的那份 Codex 配置备份。
- C6 ChatGPT 正在运行时，卸载完成后提示重启 ChatGPT，并提供「立即重启 ChatGPT」和「稍后自己重启」。
- C7 Windows 上从系统"应用和功能"发起卸载时，执行和 C2～C5 相同的步骤；遇到 C3 的情况，同样暂停并提示。
- C8 卸载完成后，入口图标消失，本机转发服务停止。

## 验收

- [ ] C1：点「卸载…」→ 出现说明弹窗；点「取消」→ 什么都没变。
- [ ] C2：卸载后 Codex 配置和安装前逐字节一致；如果安装后用户加过无关设置，这些设置仍然在。
- [ ] C3：手改一个接入项后卸载 → 出现暂停弹窗；这时检查，凭据库、工具数据、程序都还在，配置文件没有变化。
- [ ] C4：卸载后在系统凭据库里找不到本工具的条目；工具数据目录、登录启动项、合并模型目录、程序都不存在了。
- [ ] C5：卸载前后对比，ChatGPT 程序、聊天数据目录、`auth.json` 的修改时间和内容都没变；安装前的配置备份仍在。
- [ ] C6：ChatGPT 运行时卸载 → 最后出现重启提示和两个按钮。
- [ ] C7：在 Windows 上从"应用和功能"卸载 → 结果和菜单卸载的验收项 C2～C5 一致。
- [ ] C8：卸载后入口图标消失，本机转发端口不再监听。

## 验证路径

1. 安装并开启转发，在 Codex 配置里另外加一行无关设置。
2. 从菜单卸载并确认 → Codex 配置除了那一行无关设置以外，和安装前一致；凭据库、登录启动项、程序都已删除。
3. 确认 ChatGPT 和聊天记录都还在，`auth.json` 没被改动。
4. 重新安装后手改一个接入项再卸载 → 卸载暂停，没有删除任何东西。
5. 在 Windows 上从"应用和功能"卸载，重复第 2、3 步的检查。
