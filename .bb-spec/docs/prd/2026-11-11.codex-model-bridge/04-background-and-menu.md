# 常驻与菜单

## 用户故事

### P0：作为用户，我想让工具在我登录电脑时自己启动，以便打开 ChatGPT 时 Codex 一定能用

**用例（主路径）**
- 场景：小林开着转发，关机后第二天开机登录。
- 操作：不手动打开本工具，直接打开 ChatGPT 进入 Codex，用中台模型和官方模型各发一条消息。
- 预期：两条消息都正常回复；菜单栏（Windows 是任务栏通知区域）里有本工具图标，主窗口不会自动弹出。

### P0：作为用户，我想从菜单栏或托盘菜单完成常用操作，以便不必打开主窗口

**用例（主路径）**
- 场景：小林点菜单栏里的本工具图标。
- 操作：查看菜单。
- 预期：菜单从上到下依次是：
  - 标题和状态（如"转发已开启 · 后台运行中"）
  - 「转发到中台」（带勾选）、「打开配置…」
  - 「登录时启动」（带勾选）、「检查更新」
  - 「卸载模型接入助手…」、「退出模型接入助手」
  - 各组之间用分隔线隔开。

**用例（边界 / 异常）**
- 场景：转发开着时，在菜单里取消勾选「登录时启动」。预期：弹窗"关闭「登录时启动」？"，说明手动打开工具之前，Codex 的官方模型和中台模型都无法使用，并建议先关闭转发。按钮是「取消」和「仍然关闭」。
- 场景：转发开着、ChatGPT 正在运行时，点「退出」。预期：弹窗"退出模型接入助手？"，说明退出前会关闭转发、还原 Codex 配置，退出后要重启 ChatGPT。按钮是「取消」和「还原并退出」。确认后入口图标消失。
- 场景：点主窗口的关闭按钮。预期：主窗口消失，菜单栏或托盘图标仍在，转发继续工作。

## 约束

- C1 「登录时启动」默认开启。开启时，用户登录系统后工具自动启动，只在后台运行，不弹出主窗口。
- C2 「登录时启动」可以在菜单里关闭，关闭后下次登录不再自动启动；重新勾选后恢复。登录启动用的是当前用户级别的系统机制，不需要管理员权限。
- C3 转发开着时取消「登录时启动」，要先弹窗确认，说明工具没在运行时 Codex 不可用；点「取消」则保持勾选。
- C4 macOS 的入口在菜单栏，Windows 的入口在任务栏通知区域。菜单是按已确认原型自绘的面板，宽 286px，菜单项最小高度 44px，内容和顺序按「用户故事」里列的来，支持方向键选择和 Escape 关闭。
- C5 菜单顶部显示转发状态（已开启或已关闭）和"后台运行中"；「转发到中台」的勾选和主窗口的开关始终一致，从菜单切换时，ChatGPT 正在运行就先弹窗确认、确认后重启 ChatGPT，没在运行就直接切换。
- C6 关闭主窗口只隐藏窗口，后台进程、入口图标和转发都不受影响；「打开配置…」重新显示主窗口。
- C7 退出时如果转发开着，先弹窗确认；确认后还原 Codex 配置，再退出。ChatGPT 正在运行时，提示用户退出后重启 ChatGPT。转发关着时直接退出。
- C8 退出后入口图标消失，后台进程结束，不再检查更新，本机转发服务停止。
- C9 同一时间只运行一份工具；用户再次打开工具时，显示已在运行的那一份的主窗口。
- C10 本机转发服务启动失败（例如端口被占用）时，主窗口顶部显示错误提示条，说明转发服务没能启动，并提供「重试」。
- C11 主窗口底部状态区显示工具版本号、运行状态和「检查更新」。
- C12 界面使用原生桌面窗口，窗口里的按钮、输入框、开关、卡片、提示条、确认弹窗和菜单面板按已确认原型和 DESIGN.md 自绘：macOS 有交通灯按钮，Windows 有系统窗口按钮；界面上没有网页式导航。

## 验收

- [ ] C1：全新安装后注销再登录 → 工具已在运行，入口图标在，主窗口没有弹出。
- [ ] C2：取消勾选「登录时启动」后注销再登录 → 工具没有运行；重新勾选后再登录 → 工具在运行；整个过程中没有出现管理员权限请求。
- [ ] C3：转发开着时取消勾选 → 出现规定的弹窗；点「取消」→ 仍然勾选。
- [ ] C4：两个平台上菜单是宽 286px 的自绘面板，项目和顺序和规定一致；用键盘能上下选择，Escape 能关闭菜单。
- [ ] C5：在菜单里关闭转发 → 主窗口开关同步变成"已关闭"；ChatGPT 运行时会先弹出确认框。
- [ ] C6：关闭主窗口后，用中台模型发消息仍然正常；点「打开配置…」→ 主窗口重新出现。
- [ ] C7：转发开着时退出并确认 → Codex 配置已还原成打开转发前的样子，进程已结束。
- [ ] C8：退出后入口图标消失，本机转发端口不再监听，此后没有更新检查的网络请求。
- [ ] C9：工具运行中再次双击打开 → 不会出现第二个进程，已有的主窗口被显示出来。
- [ ] C10：先占用转发端口再启动工具 → 主窗口出现错误提示条和「重试」；释放端口后点「重试」→ 提示消失。
- [ ] C11：主窗口底部能看到版本号、运行状态和「检查更新」。
- [ ] C12：macOS 窗口左上角有交通灯按钮；Windows 窗口右上角有最小化、最大化、关闭按钮。

## 验证路径

1. 安装后注销再登录 → 入口图标出现，主窗口没有弹出，直接打开 ChatGPT 后两类模型都能用。
2. 点入口图标 → 菜单内容和顺序符合规定。
3. 关闭主窗口 → 图标仍在，转发正常。
4. 转发开着时取消「登录时启动」→ 先出现提醒弹窗。
5. 转发开着时退出 → 确认后配置已还原、图标消失、端口不再监听。
