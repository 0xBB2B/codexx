# 官网页面

## 用户故事

### P0：作为第一次听说这个工具的访客，我想在一页里看懂它做什么、长什么样、怎么上手，并找到下载入口

**用例（主路径）**
- 场景：小周的浏览器语言是简体中文，朋友发来官网链接。
- 操作：打开链接，从上往下滚动；在「界面长什么样」里点「首次设置」页签；点「常见问题」里的「API Key 存在哪里？」；点首屏的「下载 macOS 版 v<版本>」。
- 预期：页面显示中文；页签切到首次设置窗口的示意图；那一条常见问题展开，显示"macOS 钥匙串，Windows 凭据管理器"；浏览器直接开始下载 macOS 安装包，不经过 Releases 页面。

### P0：作为看不懂中文的访客，我想读英文版

**用例（主路径）**
- 场景：Alex 的浏览器语言是英文。
- 操作：打开官网。
- 预期：页面直接显示英文，App 界面图保持中文，图下注明 "The app’s interface is available in Chinese only."

**用例（边界）**
- 场景：小周想把英文版给同事看。操作：点右上角「English」，再刷新页面。预期：整页换成英文，网址不变；刷新后仍是英文。

- C6 「三步上手」是三张并排卡片，编号依次为 1、2、3：
  1. 「下载并安装」：先装好 ChatGPT 桌面版，再用本页的下载按钮下载安装包。安装包没有开发者签名，第一次打开要手动放行，步骤写在「下载」一节。
  2. 「填 Base URL 和 API Key」：打开模型接入助手，填中台提供的 Base URL（例如 `https://relay.example.com/v1`）和 API Key（例如 `sk-example-0000`），点「完成设置」。
  3. 「重启 ChatGPT」：助手只提示"重启 ChatGPT 后生效"，由你自己重启；重启后在 Codex 的模型列表里就能选中台模型。
- C7 「两种接入方式，自动选」区块是浅灰底：
  - 说明「助手检测 Codex 有没有登录 ChatGPT，按结果自动选一种。」
  - 流程图：「Codex（ChatGPT 桌面版）」→「模型接入助手（本机 127.0.0.1:47311）」→ 分成两路「官方服务（官方模型的请求）」和「你的中台（中台模型的请求）」。
  - 左卡片：标签「已登录 ChatGPT 时」，标题「官方 + 中台」，正文「模型列表里官方模型在上，中台模型在下。选官方模型时，请求仍然访问官方服务。」模型列表示意依次为：官方模型 A、官方模型 B、中台 · auto、中台 · 模型 A。
  - 右卡片：标签「没登录 ChatGPT 时」，标题「只用中台」，正文「不登录也能用。模型列表里只有中台模型，默认选中「中台 · auto」。登录 ChatGPT 后在主窗口点「重新检测」，就能同时用官方模型。」模型列表示意依次为：中台 · auto（标「默认」）、中台 · 模型 A。
- C8 「安全说明」：
  - 说明「全部源码公开在 GitHub 上，下面每一条都能在代码里查到。」
  - 下面是两行两列四张卡片，各带一个图标：
    - 「API Key 只存在系统凭据库」：macOS 存进钥匙串，Windows 存进凭据管理器；普通文件和日志里都没有它。
    - 「官方凭据只发往官方服务」：官方凭据只转发给官方服务，中台收不到；助手也不保存它。
    - 「配置可以原样还原」：助手只改自己的接入项；关闭转发或卸载时，Codex 配置还原为开启前的样子。
    - 「重启 ChatGPT 由你决定」：改动要重启才生效时，助手只提示"重启 ChatGPT 后生效"，什么时候重启由你定。
- C9 「常见问题」区块是浅灰底，共 7 个折叠项，第一个默认展开，点问题就展开或收起。问题和回答依次是：
  1. 没登录 ChatGPT 能用吗？——能，自动用「只用中台」方式，Codex 里只有中台模型，默认选中「中台 · auto」。
  2. 选了官方模型，请求会发给中台吗？——不会，只发给官方服务。请求先到本机的助手，再转给官方服务，官方凭据也只发往官方服务。
  3. API Key 存在哪里？——macOS 钥匙串，Windows 凭据管理器。
  4. 助手会重启我的 ChatGPT 吗？——只提示"重启 ChatGPT 后生效"，重启由你自己操作。
  5. 以后不想用了怎么办？——关闭转发即还原配置。macOS 用菜单里的「卸载模型接入助手…」，直接拖进废纸篓的话配置得不到还原；Windows 用托盘菜单或「应用和功能」卸载。卸载后 ChatGPT 和聊天数据都还在。
  6. 第一次打开被系统拦住了怎么办？——macOS：进系统设置 > 隐私与安全性，点「仍要打开」；Windows：在 SmartScreen 弹窗里点「更多信息 > 仍要运行」。
  7. 支持哪些系统？——macOS 13 及以上（Apple 芯片）和 Windows 10 1809 及以上（64 位），要先装好 ChatGPT 桌面版。
- C10 「下载」区块：
  - 说明：已发布时「最新正式版是 v<版本>，点按钮直接下载安装包。」（The latest release is v<版本>. The buttons download the installer directly.）；还没发过正式版时「正式版还没有发布。」（No release has been published yet.）
  - 两张卡片：
    - 「macOS」：Apple 芯片，macOS 13 及以上。
    - 「Windows」：64 位，Windows 10 1809 及以上。
    - 每张卡片一个绿色按钮「下载 macOS 版 v<版本>」或「下载 Windows 版 v<版本>」，直接下载，地址同首屏；还没发过正式版时换成禁用的「暂未发布」。页面任何地方不出现 `model-bridge-<版本>-macos.dmg` 这类文件名写法。
  - 卡片下方居中一个带下划线的小链接「查看所有版本」（All releases），指向 `https://github.com/0xBB2B/codexx/releases`。
  - 下方一块「首次打开要手动放行」：macOS 和 Windows 各一句放行步骤，内容同 C9 第 6 条；最后一句「升级到新版本后，钥匙串可能会问一次是否允许访问，选允许即可。」

  - 右边「GitHub 仓库」（指向 `https://github.com/0xBB2B/codexx`）和「回到顶部」。
- C12 语言：

  - 访客第一次打开时，浏览器首选语言以 `zh` 开头就显示中文，否则显示英文。
  - 访客点过语言切换后，之后再打开（含刷新）都显示他最后选的语言；浏览器存不了这个选择时，按浏览器语言显示。
  - 切换后页面的语言标记跟着变（中文 `zh-CN`、英文 `en`），浏览器标签页标题也换成对应语言。

## 验证路径

1. 把浏览器语言设为简体中文，本地打开官网文件 → 显示中文页，界面区块默认是「主窗口」图，常见问题第一条展开。
2. 点「English」→ 整页换成英文，App 界面图仍是中文，并带英文说明；刷新 → 仍是英文。
3. 把窗口拉到 375px 宽 → 单栏排列，顶栏只剩品牌、语言切换和 GitHub，没有横向滚动条。
4. 点首屏「下载 macOS 版」→ 直接下载最新正式版的 dmg；点「GitHub」→ 打开仓库首页；点「查看所有版本」→ 打开 Releases 页。
