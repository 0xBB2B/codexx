# 官网与 README 改称「中转」

## 目标
官网中文页和 README 里看不到「中台」，官网的 App 示意图和新版界面一致。

## 业务规则（来源：PRD 01-rename-relay）
- 官网中文页所有「中台」换成「中转」，首屏说明末句改为「这个页面把你自己的模型服务叫作「中转」。」；英文页的 relay 说法不变。
- 官网「界面长什么样」的三张示意图跟着新界面改：
  - 「主窗口」图：画成新布局——转发总览（浅绿底，48px 应用图标，标题「使用中转 · 已开启」，说明「官方模型在上，中转模型在下；选官方模型时仍访问官方服务。」，第二行「接入方式」灰色、「官方 + 中转」深色加粗、「· 已检测到 ChatGPT 登录」，「重新检测」）、「中转配置」卡片（两行示例配置「中转」「A家」，各带「N 个模型」，「编辑」「删除」，下面「添加配置」「已有 2 个，最多 10 个。」）、底部状态行（「v1.0.0」「后台运行中」「ChatGPT 已检测到」「中转模型 10 个（2 个配置）」「检查更新」）。
  - 「首次设置」图：大标题「连接中转服务」，加「名字」栏（「中转」）。
  - 「菜单栏菜单」图：「使用中转」，菜单栏图标换成新单色图标。
  - 图下说明文字、三步上手、两种接入方式、安全说明、常见问题里的「中台」都换成「中转」；「中台 · auto」等模型名改成「中转 · auto」；接入方式卡片的模型列表示意加上第二个配置（如「A家 · auto」）。
- 页面仍只许出现白名单网址和示例 Key（`https://relay.example.com/v1`、`sk-example-0000`，第二个配置示例用 `https://relay.example.com/alt/v1`（检查程序白名单只有 relay.example.com）），发布前检查程序要通过。
- README 里的「中台」换成「中转」。
